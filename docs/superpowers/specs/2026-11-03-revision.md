# Revision 2026-11-03: why local and remote must match

Measured with Screen Sharing (app off, keys injected):

| Local | Remote | Typed | Result |
|---|---|---|---|
| Zhuyin | Zhuyin | su3cl3 | composes 妳好 |
| ABC | Zhuyin | su3cl3 | literal `su3cl3` (no composition) |
| ABC | ABC | Shift+ABC, abc | `ABCabc` |
| Zhuyin | ABC | Shift+ABC, abc | `ABC` + `ㄇㄖㄏ` |

Screen Sharing translates keystrokes through the local input source, so the
local source must equal the remote one. The coordinator tracks the remote mode
(flipped by every Caps Lock/F17, or declared with the resync HUD), forces the
local source to it while Screen Sharing is frontmost, and restores the user's
local source on leaving. Caps Lock and lock-state events never reach the remote.
